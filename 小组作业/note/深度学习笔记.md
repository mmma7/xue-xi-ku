# 深度学习

## 1、深度学习简介

机器学习：机器学习是使用算法分析数据，从数据中学习，然后<u>==对新数据做出确定或预测==</u>的做法。
特殊：能在没有明确指令下完成任务。

深度学习：深度学习是机器学习的一个子领域，它使用受大脑神经网络结构和功能启发的算法。
ANN：在深度学习中使用的神经网络称为人工神经网络（ANN（net、neural net、model））
隐藏图层：ANN由层即神经元构成，除输入和输出图层之外的所有图层称为隐藏图层

`Keras`构建顺序模型实例

```python
from keras.models import Sequential				#导入顺序栈
from keras.layers import Dense, Activation
#构建Dense(密集层或全连接层)对象数组，每一个Dense都是层
"""
第一层有3个节点，即units的值代表层节点，input_shape 指输入的值是一个元组，其中每个元素代表一个维度的大小。（2，）表示输入的数必须是一维的且长度（即两个元素）为2如([1.0, 2.0])
"""
layers = [
    Dense(units=3, input_shape=(2,), activation='relu'),
    Dense(units=2, activation='softmax')
]
"""
relu 函数在输入大于 0 时，输出等于输入；输入小于等于 0 时，输出为 0。
softmax 函数通常用于多分类问题中，它将输入的数值转化为概率分布，使得各个输出值的范围在 0 到 1 之间，且所有输出值之和为 1。
"""
model = Sequential(layers)
```

图层权重：两个节点之间的每个连接都有一个相关的权重，每个权重表示两个节点之间的连接强度。当网络在输入层的给定节点收到输入时，此输入将通过连接传递到下一个节点，并且输入将乘以分配给该连接的权重。==节点输出 = 激活（输入的加权和）==（决定重要层度）

正向传递：对于数据集中的给定样本，从输入层到输出层的整个过程称为通过网络的正向传递。

激活函数：在人工神经网络中，激活函数是将节点的输入映射到其相应输出的函数。激活函数执行某种类型的作，将总和转换为通常介于某个下限和某个上限之间的数字。==此转换通常是非线性转换。==
指定激活函数方法：
1、在层的构建函数中`Dense(units=5, input_shape=(3,), activation='relu'`、
2、在模型实例化后将层和激活函数添加到模型中

```
model = Sequential()
model.add(Dense(units=5, input_shape=(3,)))
model.add(Activation('relu'))
```

优化算法：权重使用我们所谓的优化算法进行优化。优化过程取决于所选的优化算法。

随机梯度下降（SGD）：SGD 的目标是最小化损失函数的某些给定函数。SGD 以使此损失函数尽可能接近其最小值的方式更新模型的权重。

损失：损失是网络对图像的预测与图像的真实标签之间的误差或差异，一种常见的损失函数是均方误差 （MSE）

训练：通过我们的模型传递所有数据后，我们将继续一遍又一遍地传递相同的数据，通过网络重复发送相同数据的过程被视为训练，在此训练过程中，是模型实际学习的时间。

epoch：指在训练期间将整个数据集单次传递到网络，一旦数据集中的所有数据点都通过网络，我们就说一个 epoch 完成了。

损失函数的梯度：使用一种称为反向传播的技术完成的，计算出单个输出的损失并计算出对应单个权重的梯度并以此来更新模型的权重。

学习：指权重的更新
学习率：学习率是一个较小的数字，通常介于 0.01 和 0.0001 之间，学习率告诉我们应该朝着最小方向迈出多大的一步。
我们为学习率选择的值将需要一些测试，一个典型的准则是将其设置在 和 0.0001之间的0.01某个位置。当学习率较高可能会错过最小值，较小则会花费较多的时间。指定学习率的另一种代码`model.optimizer.learning_rate = 0.01`

==新权重 = 旧权重 - 梯度*学习率==

batch size：指定一次通过人工神经网络传递的样本数

```python
#编译模型
model.compile(
    optimizer=Adam(learning_rate=0.0001), 		#优化器Adam并确定学习率为0.001
    loss='sparse_categorical_crossentropy', 	#损失函数，计算的是实际类别和预测类别之间的交叉熵损失，对稀疏标签（即只有一个正确类别，用单个整数表示）进行优化。
    metrics=['accuracy']					   #设置了评估模型性能的指标为准确率
)
#将数据在模型上训练
model.fit(
    x=scaled_train_samples, 	#训练样本组成的numpy数组
    y=train_labels, 		    #由训练样本组成的numpy数组
    batch_size=10, 			    #指定一次应向模型发送多少个训练样本
    epochs=20,                   #将训练集传递给模型的次数
    shuffle=True, 	             #将数据集打乱
    verbose=2				    #模型训练时能看到多少日志记录。
)
```

均方误差（MSE）：实践中常用的损失函数，计算提供的输出预测与标签之间的差异（误差）,然后我们调整此误差的平方。一次将多个样本传递给模型（一批样本），将取所有这些样本的平方误差的平均值。==MSE=(output-label)(output-label)==

出于模型的训练和测试目的，我们应该将数据分解为三个不同的数据集。Training set  训练集、 Validation set  验证集、 Test set  测试集。==验证集中的数据与训练集中的数据是分开的==。
训练集：用于训练模型的数据集。可通过对其的训练去预测未见过的新数据。
验证集：是一组独立于训练集的数据集，用于在训练期间验证我们的模型。对验证集中的每个输入进行分类。它将仅根据它对训练集中正在训练的数据的了解来执行此分类。模型中的权重不会根据根据我们的验证数据计算的损失进行更新。确保模型不会过度拟合训练集中的数据。（过拟合的思路是模型变得非常擅长对训练集中的数据进行分类，但它无法对未对其进行训练的数据进行泛化和准确分类。）
测试集：测试集是一组数据，用于在模型训练后测试模型。测试集与训练集和验证集是分开的。将使用这个模型来预测测试集中未标记数据的输出。==主要区别为测试集不应该被标记==。
